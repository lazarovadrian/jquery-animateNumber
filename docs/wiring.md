# Соединения

Пока это карта, а не готовая схема. Пины прошивки и этот файл должны совпадать. Пока номера GPIO не выбраны — в прошивке стоят заглушки, моторы не крутятся.

## Правила

- Мотор — только через драйвер. Обмотка мотора не садится на GPIO.
- Общий GND: аккумулятор, драйвер, ESP32-C3.
- Питание логики драйвера (VCC) — от 3,3 В, если даташит это разрешает. Силовое питание моторов (VM) — отдельно, с аккумулятора.
- Первое включение моторов — колёса в воздухе, без пропеллеров и без нагрузки на вал.

## Карта

Заполнить, когда будет конкретная плата и конкретный драйвер.

| Сигнал | Куда | GPIO / контакт | Проверено |
| --- | --- | --- | --- |
| Левый мотор, направление A | драйвер IN1 |  | нет |
| Левый мотор, направление B или ШИМ | драйвер IN2 |  | нет |
| Правый мотор, направление A | драйвер IN3 |  | нет |
| Правый мотор, направление B или ШИМ | драйвер IN4 |  | нет |
| Сон / разрешение драйвера | nSLEEP или STBY |  | нет |
| Общая земля | GND драйвера и ESP32-C3 | GND | нет |
| Сила моторов | VM драйвера | аккумулятор | нет |

## Порядок включения

1. Прошить ESP32-C3 без драйвера. В Serial должна появиться строка `esp32c3-rc-car`.
2. Припаять или воткнуть землю и сигнальные провода. Моторное питание ещё не подавать.
3. Подать VM и проверить, что драйвер не греется на месте.
4. Короткий импульс на один мотор. Если крутится не туда — поменять местами провода этого мотора или направление в прошивке.
