# Прошивка

Каркас на PlatformIO и Arduino для ESP32-C3. Моторы отсюда ещё не крутятся: пины не назначены, чтобы случайная прошивка не дёрнула драйвер.

## Что делает сейчас

Плата поднимает Serial на 115200 и раз в секунду пишет `esp32c3-rc-car`, сколько миллисекунд она уже работает, и имя чипа. Если на плате есть светодиод на известном GPIO, его номер ставится в `LED_PIN` в `src/main.cpp`. Пока там `-1`, светодиод не трогается.

## Сборка

Из этого каталога, когда установлен PlatformIO:

```bash
pio run -e esp32-c3-devkitm-1
pio device monitor -b 115200
```

Плата по умолчанию — `esp32-c3-devkitm-1`. Для Super Mini и других модулей на том же кристалле окружение в `platformio.ini` меняется, когда будет точное имя платы.

Проверять сначала только с USB, без драйвера моторов.
